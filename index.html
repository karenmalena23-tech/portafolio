Proyecto 2: La Isla del Gran Tesoro

Para quién es y qué hace: Un juego multijugador 2D en tiempo real para dos usuarios que compiten en una carrera pirata llena de tesoros y obstáculos.

Cómo está hecho: Desarrollado como aplicación web con salas privadas y un salón de fama global. Utiliza Supabase para guardar los datos y la base de récords, y JavaScript ejecutándose en el navegador para la sincronización. Publicado en Vercel.
